# 反射神経ゲーム

このゲームは、表示された文字が現れた瞬間にできるだけ早くクリックすることで反射神経を測定するシンプルなゲームです。

---

## 🎮 ゲーム内容

- スタート後、中央に特定の文字（例：「click！」）が表示されます
- 表示されたらすぐにクリック
- 反応時間が短いほど高評価です
- 最終評価は全部で6段階あります
- 設定で問題数を変更することができます


---

## 🖥 環境情報

- 開発言語：HSP（Hot Soup Processor）
- 対応OS：Windows（HSPランタイムが必要）
- 制作時期：2022年10月ごろ

---

## 🔧 実行方法

1. [HSP公式サイト](https://hsp.tv/) からHSPをインストール
2. `main.hsp` をHSPエディタで開いて「実行」
