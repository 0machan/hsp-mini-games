# エイム練習ゲーム

このゲームは、画面に表示される円を素早く正確にクリックしてエイム（照準）力を高めるシンプルな練習ゲームです。

---

## 🎮 ゲーム内容

- ランダムな位置に出現する円を、すばやくクリックしてください
- クリック成功で次の円が表示され、スコアが加算されます
- 既定の個数をクリアする速度で点数が評価されます
- イージー/ノーマル/ハードの3段階の難易度があり、難しくなるほど的が小さくなります
- 設定で的の数を変更することができます

---

## 🖥 環境情報

- 開発言語：HSP（Hot Soup Processor）
- 対応OS：Windows（HSPランタイムが必要）
- 制作時期：2022年10月ごろ

---

## 🔧 実行方法

1. [HSP公式サイト](https://hsp.tv/) をインストール
2. `main.hsp` をHSPエディタで開いて「実行」
