# HSPミニゲーム集

このリポジトリは、部の活動で制作されたHSP（Hot Soup Processor）によるミニゲームをまとめたものです。  
講習会で使用したプログラムやその応用が主となっています。
---

## 🎮 収録ゲーム一覧

| ゲーム名 | 説明 | フォルダ |
|----------|------|----------|
| 反射神経ゲーム | 表示された文字を素早くクリックして反射神経を競うゲーム | [`reaction-game`](reaction-game/) |
| エイムゲーム | ランダムな位置に表示される円を素早くクリックするAIM練習用ゲーム | [`aim-game`](aim-game/) |
| じゃんけんゲーム | プレイヤーとコンピュータでじゃんけん勝負を行うシンプルなゲーム | [`janken-game`](janken-game/) |
| 時計（復旧予定） | デジタル時計を表示するアプリ | [`clock`](clock/) |
| ボールシミュレーション（復旧予定） | 画面内を移動するボールの動作をシミュレーションするアプリ | [`ball-simulation`](ball-simulation/) |

---

## 🛠 実行方法

すべてのゲームは HSP（Hot Soup Processor） で作成されています。以下の手順で実行できます：

1. [HSP公式サイト](https://hsp.tv/) からHSPをインストール
2. 各ゲームフォルダ内の `main.hsp` をHSPエディタで開く
3. 実行ボタンを押すとプレイ開始
