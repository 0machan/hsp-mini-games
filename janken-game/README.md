# じゃんけんゲーム

このゲームは、HSPで作成されたシンプルな「じゃんけん」ゲームです。プレイヤーがボタンをクリックして、コンピュータと勝負します。

---

## 🎮 ゲーム内容

- グー・チョキ・パーのいずれかを選択
- コンピュータの手が表示され、結果（勝ち・負け・あいこ）が判定

---

## 🖥 環境情報

- 開発言語：HSP（Hot Soup Processor）
- 対応OS：Windows
- 制作時期：2022年10月ごろ

---

## 🔧 実行方法

1. [HSP公式サイト](https://hsp.tv/) をインストール
2. `main.hsp` をHSPエディタで開いて「実行」

---

## 📝 制作背景

- 講習会で初心者向けに作成されたサンプル
- 条件分岐・乱数・表示制御など、HSPの基本構文理解に使用
